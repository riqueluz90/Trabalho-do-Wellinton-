# Meu Dia — Lista de tarefas

Aplicação de tarefas feita com Next.js e React. Permite adicionar, concluir,
excluir e filtrar atividades; as alterações são salvas no `localStorage` do
navegador.

## Executar localmente

Requisitos: Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Publicar na Vercel

1. Envie este projeto para um repositório GitHub.
2. Importe o repositório em [vercel.com/new](https://vercel.com/new).
3. Mantenha as configurações padrão do Next.js e selecione **Deploy**.

As tarefas são armazenadas no navegador de cada usuário, não em uma conta ou
banco de dados compartilhado.
